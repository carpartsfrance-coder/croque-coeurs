# Croque-Cœurs

Snake en duel pour deux : chacun joue sa manche, le meilleur score prend le point.

- Les deux joueurs d'une même manche affrontent la même graine : mêmes cœurs, mêmes bonus.
- Bonus : cœur en or (+3), coup de foudre (points doublés 6 s), bouderie (tout ralentit 6 s).
- Séries jusqu'à ×4 en enchaînant les cœurs à moins de 3,5 s d'intervalle.

Un seul fichier, aucune dépendance, aucun serveur. Les scores restent dans le navigateur.

Commandes : flèches, ZQSD, glissement du doigt, ou la croix à l'écran. Espace = pause.
